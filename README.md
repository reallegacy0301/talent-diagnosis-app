# 才能を事業に変える｜無料診断アプリ

## 概要

個人起業家・経営者向けの性格診断アプリ。4軸20問で才能と事業可能性を診断し、公式LINE登録へ誘導します。

## 技術スタック

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Vercel デプロイ対応

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

## LINEリンクの設定

`src/components/ResultCard.tsx` の以下の箇所を変更してください：

```typescript
const LINE_URL = "https://lin.ee/XXXXXXX"; // ← 公式LINEのURLに変更
```

## 診断タイプ

| タイプ | 説明 |
|--------|------|
| 💎 原石タイプ | 才能認知・価値変換力が低い段階 |
| 📚 知恵の守り人タイプ | 才能は高いが価値化できていない |
| 🏛️ ビジョナリーアーキタイプ | ビジョンはあるが事業設計が弱い |
| ⚡ 行動の先駆者タイプ | 実行力は高いが軸が定まっていない |
| 👑 統合マスタータイプ | 全軸バランスが取れている |

## 4つの診断軸

1. **才能認知** - 自己の強みを把握している度合い
2. **価値変換力** - 才能を他者への価値に変える力
3. **事業設計力** - 収益化・集客の設計力
4. **実行継続力** - 行動し続ける力

## Vercelへのデプロイ

```bash
# Vercel CLIをインストール
npm i -g vercel

# デプロイ
vercel
```

または GitHub にプッシュして Vercel ダッシュボードから連携するだけで自動デプロイされます。
